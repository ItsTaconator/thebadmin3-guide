# Background & Information About TheBadmin3
> <span style="color:#e4d00a">Expect this guide to be very disorganized and incomplete. Sorry. Additionally, any information that's missing is information I've forgotten</span>

TheBadmin3 is a server that originally my friend Anthony and I set up, and I've just been refining it and using it for more and more things over the course of roughly one and a half semesters. Since it was originally set up, it has been thoroughly used by the Patch Team for deploying games to computers in the lab, updating Windows, as well as used by me to host servers for various games for the LAN parties that the IT Club has.
