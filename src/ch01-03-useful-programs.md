# Useful Programs
These are a list of programs that will make managing the server, as well as doing things in the terminal *potentially* easier
| Name | Command | Description | Source |
| ---- | ------- | ----------- | ------ |
| neovim | `nvim` | Modern fork of Vim with IDE-like features | `apt` (Already installed) |
| yazi | `yazi` | Terminal file manager | [GitHub Releases](https://github.com/sxyazi/yazi/releases) |
| diskonaut | `diskonaut` | Terminal disk space manager | `cargo install diskonaut` (if `cargo` isn't available, run `rustup default stable`) |
| diskusage-rs | `diskusage` | Shows disk usage across all partitions | [GitHub Releases (shameless plug)](https://github.com/ItsTaconator/diskusage-rs/releases/tag/v1.0.0) |
