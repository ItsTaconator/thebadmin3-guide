TheBadmin3 Handbook

Background & Information About TheBadmin3

Expect this guide to be very disorganized and incomplete. Sorry. Additionally, any information that's missing is information I've forgotten

TheBadmin3 is a server that originally my friend Anthony and I set up, and I've just been refining it and using it for more and more things over the course of roughly one and a half semesters. Since it was originally set up, it has been thoroughly used by the Patch Team for deploying games to computers in the lab, updating Windows, as well as used by me to host servers for various games for the LAN parties that the IT Club has.

Managing systemd services

systemd services are managed with a tool called systemctl. This page will cover basic usage of systemctl. For more information, see this DigitalOcean guide or the systemctl man pages.

Remove to remove <> from service names

Start

sudo systemctl start <service name>

Stop

sudo systemctl stop <service name>

Restart

sudo systemctl restart <service name>

Start automatically on boot

sudo systemctl enable <service name>

Stop service from starting on boot

sudo systemctl disable <service name>

Start automatically on boot, and start service now

sudo systemctl enable --now <service name>

Managing Docker Compose Services

The Docker containers I've deployed are managed with Docker Compose (docker compose). This page will cover basic usage of docker compose. For more information, see the official documentation.

cd to the container's folder containing compose.yaml before running these (example: /home/dockeruser/t5server)

Make sure to remove <> from service name

Start

Focused

docker compose up <name>

Detached

docker compose up <name> -d

Stop

docker compose down <name>

Restart

docker compose restart <name>

Attach to running container console

docker compose attach <name>

Detach from console

Press Ctrl+p, then q (no ctrl)

Vim binds: <C-p>q
